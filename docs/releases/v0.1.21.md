## 简体中文

- 在预览面板中直接阅读 Word 正文、切换 Excel 工作表、翻阅和缩放 PDF、播放 GIF 动画。磁盘文件与压缩包内文件均可预览。旧版 DOC 和 XLS 使用 Windows 内容筛选器显示文本。
- 改进音频与视频开头的播放，减少起播瞬间的卡顿和爆音，并保留短音效的开头。
- 资源管理器右键压缩会显示可取消的进度窗口。打包文件夹时，文件和子目录直接位于 ZIP 根目录。
- 右键单个文件时，菜单会预览以父目录命名的 ZIP 文件名。遇到同名文件会自动追加编号。
- 使用「解压到此处」时，仅含散文件的压缩包默认解压到同名文件夹。可在「设置 → 系统集成 → 右键菜单」关闭此选项。

## 繁體中文

- 在預覽面板中直接閱讀 Word 內文、切換 Excel 工作表、翻閱和縮放 PDF、播放 GIF 動畫。磁碟與壓縮檔內的檔案皆可預覽。舊版 DOC 和 XLS 透過 Windows 內容篩選器顯示文字。
- 改善音訊與影片開頭的播放，減少開始播放時的卡頓和爆音，並保留短音效的開頭。
- 從檔案總管按右鍵壓縮時會顯示可取消的進度視窗。壓縮資料夾時，檔案與子資料夾直接放在 ZIP 根目錄。
- 在單一檔案上按右鍵，選單會預覽以上層資料夾命名的 ZIP 檔名。遇到同名檔案時會自動加上編號。
- 使用「解壓縮到此處」時，只有散檔的壓縮檔預設會解壓縮到同名資料夾。可在「設定 → 系統整合 → 右鍵選單」關閉此選項。

## English

- Preview Word text, switch Excel worksheets, browse and zoom PDF pages, and play animated GIFs from disk or inside an archive. Legacy DOC and XLS files show text through Windows content filters.
- Audio and video previews now buffer the first audio samples to reduce startup stutter and pops and preserve the beginning of short sounds.
- Compressing from File Explorer opens a cancellable progress window. When packing a folder, its contents go directly into the root of the ZIP.
- Right-click a single file to see the proposed ZIP name, based on its parent folder. If the name is taken, the menu shows the next available number.
- Extract Here now creates a matching folder by default for archives containing only top-level files. You can turn this off under Settings → System integration → Context menu.
