## 简体中文

- 开启「启动时检查更新」后，每次启动 ZipMerge 都会检查新版本。即使今天已经检查过，或上次检查时没有联网，下次启动也能发现刚发布的更新。

## 繁體中文

- 啟用「啟動時檢查更新」後，每次啟動 ZipMerge 都會檢查新版本。即使今天已經檢查過，或上次檢查時沒有連線，下次啟動也能發現剛發布的更新。

## English

- When startup update checks are enabled, ZipMerge checks for a new version each time it starts, even if you checked earlier that day or the previous request failed.
