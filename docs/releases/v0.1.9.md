## 简体中文

在目标结构中选中文件或文件夹，按 **Ctrl+F2** 即可批量重命名。也可以从右键菜单或目标结构面板右上角的「批量重命名」按钮进入。**F2** 仍用于单项改名。

- **查找替换**：按顺序应用多条规则，按文本、位置或分隔字符替换，默认保留扩展名。
- **插入内容**：在开头、指定位置或扩展名前插入文本、序号或文件信息。序号支持补零、中文数字和英文字母。
- **手动编辑**：直接修改新名称，或从 Excel 粘贴一列名称。可以调整预览顺序、排除条目，并在执行前修正冲突。

整批改名可以一步撤销。所有修改只作用于虚拟目标结构，源文件和原压缩包保持不变。

下载 **ZipMerge-Setup-0.1.9.exe** 安装或覆盖升级 Windows x64 版本，无需管理员权限。校验和、第三方许可和对应源码档案随本版提供。

## English

Select files or folders in the target tree and press **Ctrl+F2** to batch rename them. The same preview is available from the context menu and the target panel button. **F2** still renames a single item.

- Apply ordered find/replace rules by text, position or delimiter. File extensions are preserved by default.
- Insert text, sequence numbers or file information at the start, at a character position or before the extension.
- Edit names individually or paste a column from a spreadsheet. Sort or exclude rows, review final names and correct conflicts before applying.

Undo the entire batch in one step. Renaming changes only the virtual target tree; original files and archives are untouched.

Use **ZipMerge-Setup-0.1.9.exe** to install or upgrade on Windows x64 without administrator privileges. Checksums, third-party notices and corresponding source archives are included as release assets.
