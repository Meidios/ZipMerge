## 简体中文

- 修复了在资源管理器中选中多个文件后，右键菜单里没有打包选项的问题。现在可以一次把多个文件、多个文件夹或两者的混合选择打成一个 ZIP。
- 菜单会预览 ZIP 名称。多选默认使用第一项所在文件夹的名称，重名会自动编号。整次打包共用一个可取消的进度窗口。

## 繁體中文

- 修正了在檔案總管選取多個檔案後，右鍵選單缺少壓縮選項的問題。現在可以將多個檔案、多個資料夾或混合選取的項目一次壓縮成一個 ZIP。
- 選單會預覽 ZIP 檔名。多選時預設使用第一個項目所在的資料夾名稱，遇到同名檔案會自動編號。整次壓縮共用一個可取消的進度視窗。

## English

- Fixed the missing ZIP command when multiple files are selected in File Explorer. You can now pack multiple files, folders, or a mix of both into one ZIP.
- The menu previews the ZIP name. A multi-item archive takes the name of the first item's parent folder and adds a number if that name is taken. One progress window lets you cancel the entire operation.
