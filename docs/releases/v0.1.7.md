## 简体中文

**ZipMerge 0.1.7：多压缩包，一个交付工作台。**

面向 Windows 10 / 11 x64 的压缩包整理与合并工具。将多个压缩包、磁盘文件和文件夹拖入同一个工作区，整理目标结构、预览素材，再导出统一命名的 ZIP 或 7z。软件界面当前为简体中文。

### 本版内容

- 修复文件夹右键缺少“添加到当前合并会话”的问题。文件和文件夹使用同一设置开关，升级补齐缺失菜单，并保留用户已关闭的选项。
- 保留多包合并、目标树编辑、文本 / 图片 / GIF / 分声道音频波形 / 视频预览、命名模板与临时交付包。
- 支持资源管理器压缩为 ZIP、解压到此处，以及临时包的独立只读内容查看。
- 首次公开发布 Windows 安装包；补齐安装包内的 MIT 与第三方完整许可、构建信息、LGPL 共享库替换说明，并提供对应第三方源码资料。
- 清除未使用的 Qt Virtual Keyboard 及已禁用 Qt PDF 的孤立插件，加入发布校验，保持应用功能与版本号不变。

### 下载与安装

| 文件 | 用途 |
| --- | --- |
| `ZipMerge-Setup-0.1.7.exe` | Windows x64 安装包，普通用户下载此文件即可 |
| `SHA256SUMS.txt` | 安装包与资料包的 SHA-256 校验和 |
| `ZipMerge-0.1.7-ThirdParty-Notices.zip` | 完整第三方许可、来源、构建参数和替换共享库说明 |
| `ZipMerge-0.1.7-ThirdParty-Sources.7z` | 与所用版本对应的上游源码档案及清单 |

安装到当前用户目录，无需管理员权限，可覆盖安装旧版。右键菜单位于 Windows 11 的“显示更多选项”；默认打开方式需要在 Windows 中手动确认。安装包未做代码签名。

下载后可用 PowerShell 核对安装器：

```powershell
Get-FileHash .\ZipMerge-Setup-0.1.7.exe -Algorithm SHA256
```

将结果与同页 `SHA256SUMS.txt` 中该文件的记录比较。

### 验证与边界

发布流程运行完整单测、实际 7-Zip / RAR 解码器检查、打包 EXE 版本检查、许可文件哈希和 FFmpeg 二进制与构建记录核对；全部通过后才公开 Release。当前界面只有中文，RAR 仅作只读输入；不支持生成 RAR、保存编辑会话或分卷输出。音视频预览受素材编码影响，部分 RAR 特性和多 GB 素材尚未全面验证。

临时交付包随会话关闭清理，需要长期保留请使用普通导出。源压缩包不会被改写。

项目自有代码采用 MIT；Qt / PySide6、FFmpeg、7-Zip、字体及其他组件保留各自许可。详见安装目录 `_internal/legal/` 或同页的第三方资料包。

## English

**ZipMerge 0.1.7: Multiple archives. One delivery workspace.**

A Windows 10 / 11 x64 desktop application for organizing and merging archives. Bring multiple archives, local files, and folders into one workspace, arrange the output tree, preview assets, and export a consistently named ZIP or 7z deliverable. The application interface is currently Simplified Chinese.

### Changes

- Fix the missing **Add to Current Merge Session** context-menu entry for folders. Files and folders share the existing setting; upgrades repair missing registration while preserving disabled preferences.
- Retain multi-archive merging, output-tree editing, text/image/GIF/per-channel audio waveform/video previews, naming templates, and temporary delivery archives.
- Include Explorer ZIP creation, extraction here, and isolated read-only inspection of generated temporary archives.
- First public Windows installer release, with complete project and third-party license materials, build information, LGPL library replacement instructions, and corresponding third-party source archives.
- Remove unused Qt Virtual Keyboard and the orphan plugin for the already-disabled Qt PDF module, and guard against their reintroduction. Application features and version remain unchanged.

### Downloads and installation

| File | Purpose |
| --- | --- |
| `ZipMerge-Setup-0.1.7.exe` | Windows x64 installer; the only download needed for ordinary use |
| `SHA256SUMS.txt` | SHA-256 checksums for the installer and companion archives |
| `ZipMerge-0.1.7-ThirdParty-Notices.zip` | Full third-party notices, provenance, build configuration, and library replacement instructions |
| `ZipMerge-0.1.7-ThirdParty-Sources.7z` | Corresponding upstream source archives and their manifest |

Installs per user without administrator privileges and supports upgrading an existing installation. Classic context-menu actions appear under **Show more options** on Windows 11. Default file-handler changes require confirmation in Windows. The installer is not code-signed.

Verify the installer using PowerShell:

```powershell
Get-FileHash .\ZipMerge-Setup-0.1.7.exe -Algorithm SHA256
```

Compare the result with the matching entry in `SHA256SUMS.txt` on this release page.

### Verification and limitations

The release workflow runs the full test suite, bundled 7-Zip/RAR decoder checks, frozen EXE version checks, notice-integrity checks, and FFmpeg binary/build-manifest checks. The release becomes public only after they pass. The UI is currently Chinese-only. RAR is read-only input; creating RAR, saved editing sessions, and split archive output are unsupported. Media preview depends on the source codec; some RAR features and multi-GB workloads have not been comprehensively validated.

Temporary delivery archives are cleaned when their session closes. Use regular export for files to retain. Source archives are never rewritten.

ZipMerge's own code is MIT licensed. Qt/PySide6, FFmpeg, 7-Zip, fonts, and other components retain their respective terms. See `_internal/legal/` in the installation or download the companion third-party materials from this release.
