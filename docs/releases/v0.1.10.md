## 简体中文

**ZipMerge 现在可以在软件里检查更新。** 在「帮助 → 检查更新」查看 GitHub 上的最新正式版。启动时也会在后台检查，每天最多一次，可从「帮助」关闭。

- **下载并更新**：下载该版本的 Windows 安装包，核对文件大小和 SHA-256 后打开安装向导。可取消下载，程序不会自行退出。安装前请先导出需要保留的会话内容。
- **跳过此版本**：以后启动时不再提示同一版本，后续新版仍会提示。手动检查可再次查看已跳过的版本。
- **打开 GitHub Release**：用默认浏览器查看该版本的发布说明和下载文件。选择「稍后」则只关闭本次提示。

从 **0.1.9 或更早版本**升级，请先下载本页的 **ZipMerge-Setup-0.1.10.exe** 并覆盖安装。联网检查功能从 0.1.10 开始提供。安装包适用于 Windows x64，无需管理员权限。

## English

Use **Help → Check for updates** to check the latest stable GitHub release. Background startup checks run at most once a day and can be disabled in Help.

Download and verify the installer before opening the installation wizard, skip only this version, or open its GitHub release notes. Downloads can be cancelled. Manual checks can revisit a skipped release. Export any session work you want to keep before proceeding with installation.

Users of **0.1.9 or earlier** need to download **ZipMerge-Setup-0.1.10.exe** from this release once. In-app checks are available starting with 0.1.10.
