## 简体中文

ZipMerge 现在支持简体中文、繁體中文和 English。默认跟随 Windows 显示语言；如果系统首选语言都不受支持，会使用英文。

在 **设置 → 常规 → 界面语言** 选择语言，点「确定」，下次启动后生效。切换语言只改变界面文字，不会修改文件名、压缩包内容或命名模板。

使用 0.1.10 的用户可以在「帮助 → 检查更新」升级；更早版本请下载 **ZipMerge-Setup-0.1.11.exe**。

## 繁體中文

ZipMerge 現在支援簡體中文、繁體中文和英文。預設跟隨 Windows 顯示語言；如果系統偏好語言皆不受支援，則使用英文。

在「設定」的「一般」頁面選擇介面語言，按「確定」，下次啟動後生效。切換語言不會變更檔名、壓縮檔內容或命名範本。

0.1.10 使用者可從「幫助」選單檢查更新；更早版本請下載 **ZipMerge-Setup-0.1.11.exe**。

## English

ZipMerge now supports Simplified Chinese, Traditional Chinese and English. It follows the Windows display language preferences by default and uses English if none are supported.

Choose **Settings → General → Interface language**, select **OK**, then restart ZipMerge. Filenames, archive contents and naming templates stay as they are.

On 0.1.10, use **Help → Check for updates** to upgrade. On earlier versions, download **ZipMerge-Setup-0.1.11.exe**.
