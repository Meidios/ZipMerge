## 简体中文

- 临时包拖不出或无法预览时，保持软件打开，选择「帮助 → 导出临时包诊断日志…」。日志记录本次运行中的文件状态、读取错误和清理操作，不包含文件名、完整路径、压缩包内容或密码。
- 开启「启动时检查更新」后，每次启动都会检查新版。即使当天已检查过，或上次检查时没有联网，也不会再跳过本次检查。

## 繁體中文

- 臨時壓縮檔無法拖出或預覽時，保持程式開啟，選擇「說明 → 匯出臨時壓縮檔診斷記錄…」。記錄包含本次執行的檔案狀態、讀取錯誤與清理操作，不包含檔名、完整路徑、壓縮檔內容或密碼。
- 啟用「啟動時檢查更新」後，每次啟動都會檢查新版。即使當天已檢查過，或上次檢查時沒有連線，也不會再略過本次檢查。

## English

- If a temporary archive cannot be dragged or previewed, keep ZipMerge open and choose Help → Export temporary archive diagnostics. The report includes file checks, read errors and cleanup events from this run, without filenames, full paths, archive contents or passwords.
- When startup update checks are enabled, ZipMerge checks on every launch, even if you already checked that day or the previous request failed.
