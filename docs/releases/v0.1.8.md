## 简体中文

**ZipMerge 0.1.8：加密压缩包、外拖传递与高 DPI 图标修复。**

### 本版修复

- **加密压缩包（#3）**：补齐能列出文件名、但文件内容已加密的 ZIP 密码询问。使用内置 7-Zip 验证实际解密，支持错误密码重试与取消；解压、预览、拖出和合并导出共用会话内的已验证密码。
- **首次外拖（#1）**：Windows 文件传递改用原生 OLE 延迟提供完整文件列表，移除空占位文件与光标轮询。外部目标第一次取得文件列表时，内容已准备完成；进度窗口不激活、不设模态，外部传递仅使用复制动作。
- **源包外层图标（#2）**：目标树中代表原始压缩包的外层节点显示压缩包图标；改名、移动、复制后仍保持正确，普通子目录继续使用文件夹图标。
- **高 DPI 图标（#4）**：修正设备像素比重复缩放引起的放大和裁切；提供多倍率图标及新版 QSS 图像缓存。

## English

**ZipMerge 0.1.8: encrypted archives, drag export, and high-DPI icon fixes.**

### Fixes

- **Encrypted archives (#3):** request passwords for ZIP archives with public filenames but encrypted contents. Verify actual decryption with bundled 7-Zip, allow retry/cancellation, and reuse verified per-source passwords in session memory for extraction, preview, drag export, and merged exports.
- **First drag export (#1):** replace empty placeholders and cursor polling with native Windows OLE delayed file-list rendering. The first successful file-list request returns fully prepared files. Preparation progress does not activate or open a modal window, and external transfers offer Copy only.
- **Archive wrapper icons (#2):** show archive icons for source-archive wrappers in the target tree, including after renaming, moving, or copying. Ordinary subdirectories retain folder icons.
- **High-DPI icons (#4):** remove duplicate device-pixel-ratio scaling that enlarged and clipped glyphs; supply multiple icon resolutions and versioned QSS image caches.

### Verification and limitations

The local full suite passed 415 tests, including Chinese encrypted ZIP/7z samples, password retry/cancellation, preview/extraction/merged-output content checks, native IDataObject ABI calls, and the first copy through the Windows Shell. The native Windows Qt backend was exercised at simulated 100% / 125% / 150% / 170% / 200% scaling in both themes. Release CI additionally checks the actual installer payload, frozen-module regressions, dependency notices, and checksums.

Programmatic Windows Shell copying is verified, and the user separately confirmed that a fresh-session first external drag succeeds with complete content. Comprehensive coverage of all external targets, the originally affected device, and mixed-DPI monitors is not claimed. Source archives remain unchanged; RAR remains read-only input. Temporary delivery archives are cleaned when their session closes; use regular export for persistent files.
