## 简体中文

- 在目标结构中按 Ctrl+A，先选当前目录的直接子项；再按一次，选中当前树的全部条目，包括折叠的目录内容。
- 选中目标文件或文件夹后按 Ctrl+C，可在 Windows 资源管理器中按 Ctrl+V 粘贴，保留整理后的名称和目录结构。从源包栏复制则得到原压缩包。

## 繁體中文

- 在目標結構按 Ctrl+A，先選目前資料夾的直接子項；再按一次，選取目前樹狀結構的全部項目，包含已摺疊的內容。
- 選取目標檔案或資料夾後按 Ctrl+C，即可在 Windows 檔案總管按 Ctrl+V 貼上，保留整理後的名稱與目錄結構。從來源壓縮檔清單複製則會取得原壓縮檔。

## English

- In the target tree, Ctrl+A selects the current folder's direct children. Press it again to select the entire tree, including collapsed entries.
- Copy target files or folders with Ctrl+C, then paste into Windows Explorer with Ctrl+V. Exported names and folder structure are preserved. Copying from the source list copies the original archive files.
