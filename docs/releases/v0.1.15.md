## 简体中文

- **关于 ZipMerge** 现在是独立窗口，可查看版本、作者并打开 GitHub 项目主页。
- **使用帮助** 用音效与语音合包的例子，说明如何添加、整理、预览和导出素材。
- **更新提示** 在下载前显示目标版本的发布说明。升级后首次启动会显示本版变化，之后可在「帮助 → 更新记录」离线翻阅历史。
- 从上个公开版 **0.1.11** 升级还会看到：目标结构栏默认更宽，波形预览区分声道；用日历图标控制文件名日期，自定义版本可直接在加宽的下拉框内输入，命名模板会记住这些设置。

## 繁體中文

- **關於 ZipMerge** 現在是獨立視窗，可查看版本、作者並開啟 GitHub 專案首頁。
- **使用說明** 以音效與語音合併封裝為例，說明如何加入、整理、預覽及匯出素材。
- **更新提示** 在下載前顯示目標版本的版本說明。升級後首次啟動會顯示本版變更，之後可在「說明 → 更新記錄」離線瀏覽歷史。
- 從上個公開版 **0.1.11** 升級還會看到：目標結構欄預設更寬，波形預覽區分聲道；用日曆圖示控制檔名日期，自訂版本可直接在加寬的下拉式方塊內輸入，命名範本會記住這些設定。

## English

- **About ZipMerge** now shows the version, author and GitHub project page in a dedicated window.
- **Usage guide** walks through importing, organizing, previewing and exporting an audio delivery.
- **Update available** shows release notes before downloading. After an upgrade, the first launch shows what changed. Reopen Help → Release history to browse older notes offline.
- Upgrading from the last public release, **0.1.11**, also gives you a wider target tree and separate waveform channels. Use the calendar icon to include today's date, type a custom version directly in the wider dropdown, and save these choices in a naming template.
