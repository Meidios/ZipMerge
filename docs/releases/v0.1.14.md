## 简体中文

- 默认三栏给目标结构留出更多宽度；选中行和来源色块更容易辨认。
- 音频预览区分声道、时间刻度和播放头。
- 日期改为日历图标开关；自定义版本可直接在加宽的下拉框里输入。

## 繁體中文

- 預設三欄配置為目標結構保留更多寬度，選取列與來源色塊更容易辨認。
- 音訊預覽區分聲道、時間刻度與播放頭。
- 日期改為日曆圖示開關；自訂版本可直接在加寬的下拉式方塊中輸入。

## English

- A wider target tree, a selection stripe, and source color markers make the workspace easier to scan.
- Audio previews distinguish channels, time ticks and the playhead.
- Toggle the date with the calendar icon and type custom versions directly in the wider dropdown.
